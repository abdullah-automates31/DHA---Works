# Glossary

| Term | Meaning |
| --- | --- |
| **DHA** | Defence Housing Authority, Karachi; the area DHA Works serves |
| **Phase** | A DHA subdivision, Phase 1 to 8; used to match workers to jobs |
| **Resident / customer** | A DHA resident using the DHA Works app; approved by staff before posting |
| **Approved / Verified** | A worker or resident approved by DHA staff after manual document review |
| **Pending review** | Applied and awaiting staff review; cannot post, quote or see jobs |
| **Needs changes** | Staff asked a resident to correct something and resubmit |
| **Visit HQ** | Staff decision asking a worker to come to the DHA office in person |
| **Suspended** | An account blocked after a report outcome |
| **Draft** | A job saved privately by the resident; not visible to workers |
| **Open** | A posted job visible to matching approved workers; lasts 24 hours |
| **Interested** | At least one worker has marked interest in an open job |
| **Quote** | A worker's itemised price: labour, materials, other, plus a visit window; final once sent |
| **Quoted** | At least one live quote exists on the job |
| **Accept** | The resident chooses one quote; it is atomic; the others become *not selected* |
| **Not selected** | A worker's quote that was not chosen |
| **Scheduled** | A quote was accepted; visit window agreed. The `accepted` status is unused for now. |
| **Expired** | An open job nobody accepted within 24 hours; the resident can repost |
| **Repost** | One-tap copy of an expired job into a new open job |
| **Completed** | The worker states the job is finished |
| **Cash collected** | Worker and resident recorded the same amount paid |
| **Disputed** | Cash amounts differ, or a report is open |
| **Reviewed** | The resident rated the worker (anonymous to the worker) |
| **Report** | A problem or "I feel unsafe" report; staff outcomes: no action, warning, suspend |
| **Helpline 1092** | The DHA staff helpline shown in both apps |
| **MVP 1 / MVP 2** | First release / next release (quote revisions) |
| **Admin / staff** | DHA team member using the web portal |
| **CNIC** | Computerised National Identity Card, the Pakistani national ID |
| **RLS** | Row Level Security: database rules limiting who can see or change each row |
| **RPC** | A SQL function the apps call to perform a checked action |
| **pgTAP** | Testing framework for Postgres |
| **pg_cron** | Postgres scheduler used for expiry and reminders |
| **Edge Function** | Server-side code on Supabase for things the database cannot do (push) |
| **EAS** | Expo Application Services; cloud builds for the mobile apps |
| **Expo Go** | App for running Expo projects on a phone during development |
| **Monorepo** | One repository holding all apps and shared packages |
| **Audit log** | Append-only record of important actions |
